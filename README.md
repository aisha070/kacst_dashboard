# مبادرة تعريف برامج الدعم والحوافز المالية — KACST Dashboard

## الملفات في هذا Repository

```
index.html       ← الصفحة الرئيسية
style.css        ← التصميم والألوان
config.js        ← إعدادات الشيت (الوحيد الذي تحتاج تعدّله)
app.js           ← منطق الداشبورد
kacst-logo.svg   ← شعار KACST
```

### تبويب `programs` — البرامج
أعمدة الهيدر (الصف الأول):

```
id | cat | cat_label | src | name | financial_support | target | services | url | hasFinancial | isNew | isClosed
```

مثال على صف:

| id | cat | cat_label | src | name | financial_support | target | services | url | hasFinancial | isNew | isClosed |
|----|-----|-----------|-----|------|-------------------|--------|----------|-----|--------------|-------|----------|
| 1 | ntdp | NTDP | NTDP | تمكين رواد الأعمال (Boost) | مكافأة 20,000 ريال | رواد الأعمال السعوديون | ورش عمل تفاعلية | https://ntdp.gov.sa/tamkeen | TRUE | FALSE | FALSE |

**قيم عمود `cat` المقبولة:**

| قيمة cat | الجهة |
|----------|-------|
| `ntdp` | البرنامج الوطني لتنمية التقنية |
| `industry` | وزارة الصناعة والثروة المعدنية |
| `smebank` | بنك المنشآت الصغيرة والمتوسطة |
| `municipalities` | وزارة البلديات والإسكان |
| `modon` | مدن |
| `monshaat` | منشآت |
| `exports` | هيئة تنمية الصادرات |
| `tourism` | صندوق التنمية السياحي |
| `sdb` | بنك التنمية الاجتماعية |
| `universities` | الجامعات |
| `nonprofit` | المؤسسات غير الربحية |

## النشر على GitHub Pages

1. أنشئي repository جديد على GitHub
2. ارفعي الملفات الخمسة: `index.html`, `style.css`, `config.js`, `app.js`, `kacst-logo.svg`
3. اذهبي إلى: **Settings → Pages → Source → Deploy from a branch → main → / (root) → Save**
4. الموقع يصبح جاهزاً خلال دقيقة على: `https://USERNAME.github.io/REPO-NAME/`

## تعديل الإيميل

**من الكود:** افتحي `index.html` وعدّلي `vfund@kacst.gov.sa`

**من الشيت:** في تبويب `about` أضيفي صفاً:
```
key = header_email
value = البريد الجديد
```
ثم اضغطي زر "تحديث البيانات" في الداشبورد.

## ترتيب تحميل الملفات (مهم)

في `index.html`، الملفات تُحمّل بهذا الترتيب:
```html
<script src="config.js"></script>   ← أولاً: الإعدادات
<script src="app.js"></script>      ← ثانياً: المنطق
```
**لا تغيري هذا الترتيب.**
